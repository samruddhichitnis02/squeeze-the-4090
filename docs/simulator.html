Inference optimisation lab: interactive simulator

RTX 4090, BERT fine-tuning and Qwen2.5-1.5B serving. Tabs 1 and 2 show measured numbers from this repository; tab 3 is a simulation.

Each line is one technique, thick = selected. Red x = a measured out-of-memory failure. Dotted line = usable VRAM cap (PyTorch is capped at 95% of the memory free at start, so overflow is a real error). Only combinations that were actually run are shown.
Open-loop Poisson arrivals, 128 output tokens per request, Qwen2.5-1.5B on vLLM 0.32. Latency is flat until near capacity, then queueing makes it explode. The online plateau (about 18 to 22k tokens/s) is set by the Python API stack, not the GPU (engine-only: 28.7k tokens/s).
Left: one cell per sequence slot (filled = being decoded). Bar: requests waiting. Line: queue length over simulated time. Model: each decode step takes ms, with N requests in flight (fitted to the measured bf16 load test). It tracks measured median latency within about 8% up to 128 req/s, and it knows nothing about the HTTP/Python stack that limits the real server at about 140 req/s.
